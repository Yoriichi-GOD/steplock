# Definition of Done and evidence gates

- [ ] Fresh repository, visible authentic progress, remote verified.
- [ ] Actual pixel decoding, board homography, strict zone membership.
- [ ] Independent observations; duplicates, reversed time, blur and missing anchors HOLD.
- [ ] Valid recipe DAG, wrong component/zone/order, explicit missing-part checkpoint.
- [ ] Correction preserves historical evidence; no invented absence or order claim.
- [ ] Camera/replay/upload paths, bounded capture, graceful stop and source loss.
- [ ] Integrated responsive Studio, editable recipes, Evaluation Lab, Evidence, Demo Kit.
- [ ] Synthetic fixture suite, isolated truth, three measured experimental arms.
- [ ] Metrics with denominators, failure cases, honest latency clocks and provenance.
- [ ] API, integration, browser, build and clean-launch checks.
- [ ] Marker kit, setup guide, reports, screenshots, README and final truth table.
- [ ] Consented staged real footage evaluated, or explicitly NOT_PROVIDED.

No physical capture consent or staged recordings were supplied at build start.
Synthetic success cannot close the real-camera validation gate.
