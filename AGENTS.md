# STEPLOCK engineering contract

Fresh implementation for Theme 04. Do not import REFLEX or other projects.
Build → measure → verify → close → expand. Keep changes and real push checkpoints
within 45 minutes. Never change commit timestamps or force-push.

Predictions consume pixels, source timestamps and a validated recipe only. Ground
truth is evaluator-only. Mark synthetic data visibly. Never imply physical safety
certification, intrinsic part identity, fastening, torque, or fatigue detection.

PASS requires independent temporal support, proven order, usable current capture,
current calibration, no unresolved violation, and an explicit checkpoint.
Occlusion is not proof of absence. Duplicate images cannot count as fresh support.
Preserve append-only events, source/frame hashes and failed experiment runs.

Definition of Done: runnable offline app; actual ArUco decoding; recipe and temporal
tests; safe failure handling; integrated UI; three measured baselines; immutable
evidence exports; authentic screenshots; documented gaps; verified remote push.
Real camera validation remains NOT_PROVIDED until consented footage is tested.
